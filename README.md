# WSL Copy

Copy real files from WSL to Windows clipboard, enabling paste to apps like WeChat.

## Features

- Right-click file in explorer → **Copy Real File**
- Supports multiple file selection

## Installation

Download `.vsix` from [Releases](../../releases) and install:
```
code --install-extension wsl-copy-*.vsix
```

## Usage

1. In VSCode WSL, right-click a file
2. Select "Copy Real File"
3. Paste to WeChat or other Windows apps
